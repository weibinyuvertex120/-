# Portrait Craft · 人像处理指南

本文档定义人像照片的专业处理能力，包括判断顺序、技术路径、朦胧感定义、风格选择、能力契约和结果评价。人像处理是见相的高质量场景之一，不是独立工具。

---

## 一、人像处理的判断顺序

### 1. 先确认任务与边界

读取或询问：

- **照片用途**：个人留存、社交媒体、作品集、封面、商业、人像系列等。
- **目标气质**：自然、清透、柔和、朦胧、冷静、明亮、克制或其他。
- **希望保留的特征**：身份、年龄、表情、皮肤纹理、发型、服装、背景关系和现场感。
- **允许的改造范围**：校正、修饰、风格化、背景处理、局部生成或概念重构。
- **真实性模式**：纪实、表达或概念。
- **目标媒介和观看尺寸**。

用户只说"变漂亮"或"更有质感"时，先把它拆成可确认的目标，例如：

```text
主体更突出
皮肤更干净但保留纹理
光线更柔和
背景更安静
色彩更统一
高光更有空气感
```

### 2. 再做事实观察

不要把审美判断伪装成事实。至少观察：

- 人物在画面中的位置、比例、姿态和视线方向。
- 面部和身体是否存在明显遮挡、边缘问题或不自然变形。
- 光源方向、面部受光、阴影、高光和肤色表现。
- 皮肤纹理、临时性瑕疵、真实特征和可能的压缩/锐化痕迹。
- 头发、服装、配饰、背景和边缘是否有干扰。
- 人物与背景的色彩、亮度、清晰度和空间关系。
- 原片是否已经有情绪、气质、动作或可利用的光线。

### 3. 区分"可修瑕疵"和"真实特征"

**不要默认移除**：
- 皮肤纹理
- 痣、雀斑、皱纹或其他稳定外观特征
- 五官结构
- 身体自然比例
- 发型和服装特征
- 有意保留的颗粒、模糊、阴影和偏色

**可以在不改变人物身份和核心特征的前提下，判断是否修复**：
- 临时性痘痘、污点、灰尘、飞发、衣物折痕、背景杂物。
- 由光线或压缩造成的局部异常。
- 明显影响观看的边缘瑕疵、色偏和过度锐化。

**每个修饰动作都要说明**：

```text
修什么
为什么修
是否可逆
是否会改变人物识别
修到什么强度停止
```

## 二、人像处理的四层技术路径

### L1 基础显现

优先处理原片已有但未被正确呈现的信息：

- 曝光和白平衡。
- 高光、阴影和反差。
- 肤色与环境色分离。
- 轻度降噪、锐化和压缩修复。
- 镜头畸变、色差和边缘问题。
- 抑制手机 HDR、过度锐化、磨皮和蜡质感。

**目标**：让人物和光线回到可读、可信、自然的基础状态。

### L2 人像关系重构

当问题来自构图和空间关系时处理：

- 裁切和比例。
- 人物位置和视觉落点。
- 视线方向前的留白。
- 背景降对比或清理干扰。
- 人物与背景的层级。
- 必要时进行轻度景深或空间分离。

**注意**：不能为了居中而破坏人物视线、动作方向或叙事留白。

### L3 人像审美增强

当基础结构成立但照片仍缺少完成度时处理：

- 局部光影塑形。
- 面部与身体的自然明暗关系。
- 肤色和服装色彩的协调。
- 背景色彩和主体色彩的关系。
- 微对比、质感、空气透视和空间层次。
- 放大原片已有的情绪和气质。
- 系列照片之间的色彩、光线和质感统一。

**注意**：增强不能把人物变成模板化"网红脸"，也不能用效果掩盖构图、光线或表情问题。

### L4 表达性或生成性重构

只有在以下情况才考虑：

- 原片缺少完成目标所需的背景或空间条件。
- L1-L3 无法解决主问题。
- 用户明确要求背景、光线、空间或风格的表达性改变。
- 任务本身是概念图、广告视觉或非纪实创作。

**必须说明**：
- 生成了什么。
- 哪些内容来自原片。
- 哪些内容属于新的表达。
- 是否改变了现场事实或人物关系。
- 是否需要用户确认。

## 三、"朦胧感"的技术定义

朦胧感不是单一滤镜，也不是把整张照片降低清晰度。先判断用户要的是哪一种：

### 1. 光学朦胧

**来源**：逆光、散射光、柔光、高光扩散。

**处理方向**：
- 保留主体核心清晰度。
- 只在高光和背景区域形成柔和扩散。
- 控制高光 roll-off，避免白雾覆盖脸部细节。
- 保留光源方向和空间关系。

### 2. 空气朦胧

**来源**：雾、空气透视、远近层次、低微对比。

**处理方向**：
- 背景降低微对比和饱和度。
- 主体保持必要清晰度。
- 远景更柔和，近景不被全部抹平。
- 使用深度或区域关系控制，而不是整图模糊。

### 3. 质感朦胧

**来源**：柔焦、轻微纹理扩散、低反差和细腻高光。

**处理方向**：
- 轻度柔化局部高频细节。
- 保留眼睛、发丝、服装和主体轮廓的可读性。
- 颗粒、柔化和高光扩散分别控制。
- 不用"磨皮"替代质感设计。

### 4. 色彩朦胧

**来源**：低饱和、柔和色阶、相邻色关系和轻微色彩空气感。

**处理方向**：
- 保留肤色可信度。
- 降低背景色彩竞争。
- 控制高光和阴影的色相关系。
- 不默认套粉色、奶油色、青橙或复古黄。

### 朦胧感停止标准

如果出现以下情况，停止或回退：

- 脸部和眼睛失去识别度。
- 皮肤变成塑料或蜡质。
- 主体轮廓消失。
- 背景和人物无法分层。
- 光源方向不可信。
- 朦胧效果比人物和情绪更先被看见。

## 四、风格选择原则

风格不是预设按钮，而是为任务服务的表达方式。

**默认基线**：

```text
自然真实编辑感 / Clean Natural Editorial
```

它可以根据人物、场景和目标偏移为：

- 清透自然
- 柔和空气感
- 克制朦胧
- 轻微 editorial polish
- 更明确的情绪化光色
- 概念化表达

**每次偏移必须说明**：

```text
解决了什么问题
放大了什么潜力
牺牲了什么
怎样避免风格盖过人物
```

## 五、能力调用契约

调用具体图像能力前必须说明：

- 输入图片和来源。
- 处理区域或 mask。
- 目标效果。
- 允许改变的内容。
- 必须保留的内容。
- 编辑强度：subtle / moderate / strong / generative。
- 预期副作用。
- 失败 fallback。

**优先级**：

```text
确定性校正
-> 局部修饰
-> 局部光色和空间处理
-> 局部生成
-> 全局生成性重构
```

## 六、结果评价

人像结果不能只看"更白、更瘦、更精致"或单一美感分数。至少评价：

- 人物身份是否保持。
- 年龄感和核心外观是否被擅自改变。
- 皮肤是否干净但仍有真实纹理。
- 眼睛、头发、服装和轮廓是否自然。
- 主体是否更突出。
- 光线是否更有方向和层次。
- 色彩是否更统一并服务人物。
- 背景是否降低干扰但仍保留必要叙事。
- 朦胧感是否只在需要的区域和强度内成立。
- 是否出现塑料皮肤、蜡质感、边缘光晕、假景深、假光源或 AI 变形。
- 是否仍然像一张照片，而不是效果演示。
- 是否满足用户目标和目标媒介。

**结果状态**：

```text
通过
部分通过
不通过
阻塞
```

## 七、安全与人物边界

- "少女"无法确认年龄时，不改变年龄，不进行性化、裸露、诱导性姿态或身体夸张改造。
- 不改变人物身份、面部结构或关键生理特征来制造"更美"。
- 不把标准化审美、白皙、纤瘦或模板化五官当作默认质量标准。
- 不把稳定外观特征自动视为瑕疵。
- 纪实、证据、新闻或公共信息场景下，禁止生成性改变人物或现场事实。
- 涉及他人肖像和公开发布时，保留用户授权和发布边界。

## 八、人像处理与通用改造模型的关系

人像处理是见相的高质量场景之一，不是独立工具。它遵循通用改造模型的四级梯度：

| 通用等级 | 人像对应 | 典型处理 |
|----------|----------|----------|
| L1 显现 | L1 基础显现 | 曝光、白平衡、肤色、降噪、锐化、抑制手机感 |
| L2 重构 | L2 人像关系重构 | 裁切、人物位置、视线留白、背景清理 |
| L3 增强 | L3 人像审美增强 | 光影塑形、肤色协调、情绪放大、系列统一 |
| L4 生成重构 | L4 表达性或生成性重构 | 背景生成、空间补全、光线重建 |

人像处理在通用模型基础上增加了：
- 人物身份和特征保护
- 皮肤纹理和真实感保留
- 朦胧感的四种类型定义
- 人像特有的安全边界
