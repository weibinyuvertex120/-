# Strategy Routing · 策略路由

本文档定义从问题/根因到视觉策略和能力类别的路由规则，包含四级改造模型、最小有效改造原则、fallback 和禁用项。

---

## 四级改造模型

四级是决策梯度，不是固定流水线。根据缺失类型和可恢复性选择等级，可以跳级、降级或停止。

### L1 显现

**适用条件**：原片信息存在，但被技术问题掩盖

**典型缺失类型**：
- technical (recoverable)
- color (recoverable)
- light (recoverable)

**典型处理**：
- 曝光和白平衡校正
- 明暗和反差调整
- 色彩恢复
- 高光与阴影恢复
- 降噪、锐化、压缩修复
- 减少 HDR、过度锐化、磨皮和计算摄影痕迹

**能力类别**：确定性编辑

**目标**：显现原片已有的信息，不凭空增加关键内容

### L2 重构

**适用条件**：素材内容有价值，但画面关系不成立

**典型缺失类型**：
- composition (reconstructable)
- subject_hierarchy (reconstructable)

**典型处理**：
- 裁切和比例调整
- 主体尺度和位置调整
- 留白重组
- 边缘清理
- 背景竞争降低
- 视线和视觉落点重排
- 必要时做可解释的几何校正

**能力类别**：确定性编辑、局部编辑

**目标**：让已有内容形成更清晰的构图关系

### L3 增强

**适用条件**：结构基本成立，但光色、层次、空间、情绪或视觉语言不足

**典型缺失类型**：
- depth (enhanceable)
- emotion (enhanceable)
- consistency (enhanceable)

**典型处理**：
- 局部光影调整
- 色彩层级优化
- 主体与背景分离
- 空间纵深增强
- 原有情绪放大
- 系列视觉统一
- 克制的材质和质感处理

**能力类别**：局部编辑、几何/深度重构

**目标**：放大原片已有潜力，不能用装饰替代问题解决

### L4 生成重构

**适用条件**：原片缺少完成目标所必需的视觉条件，或用户明确要求表达性重构

**典型缺失类型**：
- any (generative_required)

**典型处理**：
- 背景生成或扩展
- 空间补全
- 光线重建
- 关键元素重构
- 概念化表达
- 深度合成

**能力类别**：局部生成、全局生成性重构

**进入条件**（必须同时满足）：
- L1-L3 已尝试且无法解决主问题，或原片明显缺少目标所需的关键视觉条件
- 用户明确要求表达性或概念性重构
- 真实性模式允许

## 路由原则

1. **最小有效改造原则**：选择能达到目标的最小改造级别。
2. **确定性编辑优先**：结果可预测、可逆、风险低的操作优先。
3. **逐级升级**：能通过 L1 完成，不升级到 L2；能通过 L2 完成，不升级到 L3；能通过 L3 完成，不升级到 L4。
4. **解决主问题**：策略必须针对已诊断的主问题，不是装饰性增强。
5. **保留潜力**：策略应保留或放大已识别的素材潜力。
6. **可偏离基线**：默认自然真实编辑感，但可根据任务偏离。

## 默认视觉基线与偏离

### 自然真实编辑感 (Clean Natural Editorial)

**定义**：真实、克制、清晰、有编辑意识的默认方向

**特点**：
- 不追求过度风格化
- 保留素材的真实感和自然感
- 克制、清晰、有编辑意识

**适用场景**：
- 普通生活照片
- 人像摄影
- 街景摄影
- 旅行摄影
- 产品摄影
- 室内摄影

### 允许偏离的情况

| 场景 | 基线 | 偏离方向 | 偏离理由 |
|------|------|----------|----------|
| 纪实、证据、新闻 | 真实优先 | 校正性编辑为主 | 保持事实准确性 |
| 普通生活、人像、街景、旅行、产品、室内 | 自然真实编辑感 | 默认起点 | 平衡真实感和表达性 |
| 强情绪、广告、概念图、艺术表达 | 诊断后偏离 | 允许更强表达 | 任务需要 |

## 能力调用优先级

### 优先级顺序

```text
确定性编辑
-> 局部编辑
-> 几何/深度重构
-> 局部生成
-> 全局生成性重构
```

### 优先级说明

| 优先级 | 能力类别 | 特点 | 适用等级 |
|--------|----------|------|----------|
| 1 | 确定性编辑 | 结果可预测、可逆、风险低 | L1-L2 |
| 2 | 局部编辑 | 针对性强、副作用可控 | L2-L3 |
| 3 | 几何/深度重构 | 结构性改变、需要谨慎 | L3 |
| 4 | 局部生成 | 补充性生成、需要标注 | L3-L4 |
| 5 | 全局生成性重构 | 深度改变、需要充分理由 | L4 |

### 最小有效改造原则

- 能通过 L1 完成，不升级到 L2
- 能通过 L2 完成，不升级到 L3
- 能通过 L3 完成，不升级到 L4

## 真实性模式路由

### 纪实模式

**触发条件**：涉及新闻、证据、身份、敏感场景或公共声明

**允许操作**：
- 校正性编辑（曝光、白平衡、裁切）
- 临时性干扰移除

**禁止操作**：
- 添加、移除或改变画面中的事实元素
- 生成内容完全禁止

**路由限制**：只能路由到 L1，不能进入 L2-L4

### 表达模式（默认）

**触发条件**：艺术、创意、个人表达、社交媒体或情绪传达

**允许操作**：
- 风格化、局部重构、合成和生成
- 生成内容需标注

**禁止操作**：
- 将生成内容伪装为原素材事实
- 改变素材的核心事实

**路由限制**：可以进入 L1-L4，但 L4 需要充分理由

### 概念模式

**触发条件**：广告、概念图、情绪板、视觉探索或抽象表达

**允许操作**：
- 深度重构和生成
- 可改变素材的语义

**禁止操作**：
- 未标注的生成内容

**路由限制**：可以进入 L1-L4

## 用户表达到策略路由

### "灰" / "平"

**诊断方向**：光线和色彩问题

**路由**：
1. 先判断 L1 是否可解决
2. 如果 L1 无法解决，考虑 L2-L3
3. 如果是表达意图，可能不需要处理

### "没构图"

**诊断方向**：构图和主体层级问题

**路由**：
1. 先判断是否真的没构图，还是构图平淡
2. 如果是构图问题，路由到 L2
3. 如果是主体问题，可能需要 L2-L3

### "没层次"

**诊断方向**：光线和空间问题

**路由**：
1. 先判断是光线层次还是空间层次
2. 光线层次：L1-L3
3. 空间层次：L3

### "不出片"

**诊断方向**：综合问题

**路由**：
1. 先诊断具体问题
2. 按缺失类型路由
3. 不能直接套用风格滤镜

### "没情绪"

**诊断方向**：情绪和叙事问题

**路由**：
1. 先判断素材是否本来就没有情绪
2. 如果有情绪但被压制，L1-L3
3. 如果需要表达性情绪，L3-L4

### "手机感强"

**诊断方向**：计算摄影痕迹问题

**路由**：
1. 先识别手机感来源
2. 针对性处理，不是套胶片滤镜
3. 主要是 L1-L2

### "想要高级感"

**诊断方向**：需要追问具体目标

**路由**：
1. 不能直接转换为风格滤镜
2. 必须追问"高级感"具体指什么
3. 转换成可验证的视觉目标后再路由

## Fallback 规则

### L4 失败

**Fallback**：
- 回到 L3，尝试增强策略
- 回到诊断，重新分析问题
- 停止并说明原因

### L3 失败

**Fallback**：
- 回到 L2，尝试重构策略
- 回到诊断，重新分析问题
- 停止并说明原因

### L2 失败

**Fallback**：
- 回到 L1，尝试显现策略
- 回到诊断，重新分析问题
- 停止并说明原因

### L1 失败

**Fallback**：
- 停止并说明原因
- 说明原片可能无法满足目标

## 禁用项

### 通用禁用项

- 不能用装饰替代问题解决
- 不能用风格滤镜替代诊断
- 不能把生成内容伪装为原片事实
- 不能忽略真实性模式限制

### L1 禁用项

- 不能凭空增加关键内容
- 不能改变素材核心事实

### L2 禁用项

- 不能破坏素材的表达潜力
- 不能做无理由的裁切

### L3 禁用项

- 不能用装饰替代问题解决
- 不能忽略主体识别

### L4 禁用项

- 不能没有充分理由进入 L4
- 不能把生成内容伪装为原片事实
- 不能忽略真实性模式限制

---

## 评价标准

### 通用评价标准

- 主问题是否解决
- 潜力是否保留或放大
- 是否引入新问题
- 是否知道何时停止

### L1 评价标准

- 技术问题是否解决
- 原片信息是否显现
- 是否凭空增加内容

### L2 评价标准

- 构图关系是否清晰
- 主体是否突出
- 是否保留素材潜力

### L3 评价标准

- 表达是否增强
- 是否用装饰替代问题解决
- 是否保留真实感

### L4 评价标准

- 是否有充分理由
- 生成内容是否标注
- 真实性模式是否允许
- 是否知道何时停止
