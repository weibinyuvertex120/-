# Security Policy

## Scope

Seeform may process personal photographs. Keep original images, generated candidates, API keys, model weights, and runtime evidence outside public repositories unless you have explicit permission to publish them.

## Reporting a vulnerability

Please do not disclose security-sensitive details in a public issue. Contact the maintainer through the GitHub profile associated with this repository and include:

- affected version;
- reproduction steps;
- impact;
- proposed mitigation, if known.

## Privacy boundary

Seeform does not include photos or model weights in the public bundle. Host adapters are responsible for their own data retention, network, and credential policies.
