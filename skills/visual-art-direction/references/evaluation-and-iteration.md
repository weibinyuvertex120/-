# Evaluation and Iteration · 评价与迭代

本文档定义视觉改造结果的评价维度、停止条件和迭代规则。

---

## 评价原则

1. **回到任务**：评价必须基于视觉任务是否达成，不是主观美感。
2. **多维度平衡**：不能只看一个维度，要综合评估所有维度。
3. **对比原图**：所有评价必须与原图对比，不是与抽象理想对比。
4. **证据支持**：每个判断都需要具体的观察证据支持。
5. **风险意识**：始终关注真实性风险和副作用。
6. **停止勇气**：当停止条件满足时，果断停止，不盲目继续。

---

## 评价维度

### 1. 目标完成度

评估视觉任务是否达成。

| 等级 | 标准 |
|------|------|
| 通过 | 目标状态已实现，观众能在目标媒介下感受到预期效果 |
| 部分通过 | 方向正确，但目标状态未完全实现 |
| 不通过 | 目标未达成，或达成方式与任务要求不符 |

**评价要点**：
- 观众是否能在目标媒介下感受到预期效果
- 任务句中的"从...转向..."是否实现
- 成功标准是否被满足

### 2. 问题改善

评估已诊断的问题是否得到解决。

| 等级 | 标准 |
|------|------|
| 通过 | 主问题已解决，次问题有改善或不再影响目标 |
| 部分通过 | 主问题有改善但未完全解决，或次问题仍存在 |
| 不通过 | 主问题未解决，或问题被转移到其他维度 |

**评价要点**：
- 与原图对比，主问题是否有明显改善
- 改善是否可量化或可感知
- 是否引入了新的问题
- 手机感或计算痕迹是否被有效处理

### 3. 语义保持

评估素材的核心语义是否被保留。

| 等级 | 标准 |
|------|------|
| 通过 | 主体、关系、空间、情绪、事实均被准确保留 |
| 部分通过 | 主体保留，但部分关系或细节被改变 |
| 不通过 | 主体被改变，或核心语义被扭曲 |

**评价要点**：
- 主体是否仍是原素材的主体
- 空间关系是否准确
- 情绪温度是否与原素材一致
- 事实元素是否被改变

### 4. 技术质量

评估结果的技术指标是否达标。

| 等级 | 标准 |
|------|------|
| 通过 | 分辨率、锐度、色彩空间、动态范围满足目标媒介 |
| 部分通过 | 基本达标，但存在可接受的技术瑕疵 |
| 不通过 | 存在明显技术缺陷，影响观看或使用 |

**评价要点**：
- 分辨率是否足够
- 细节是否清晰
- 色彩空间是否正确
- 动态范围是否保留
- 是否引入伪影、噪点、失真

**特殊情况**：技术瑕疵可能是表达的一部分（如颗粒感、柔焦），根据创作意图判断。

### 5. 媒介适配

评估结果是否适合目标媒介和观看环境。

| 等级 | 标准 |
|------|------|
| 通过 | 比例、安全区、缩略图识别、字幕空间均满足要求 |
| 部分通过 | 主要要求满足，次要要求有妥协 |
| 不通过 | 不满足目标媒介的核心要求 |

**评价要点**：
- 比例是否正确
- 主体是否在安全区内
- 缩略图是否可识别
- 是否预留文字空间
- 在连续播放中是否有足够停留

### 6. 真实性风险

评估结果是否存在真实性边界被破坏的风险。

| 等级 | 标准 |
|------|------|
| 通过 | 生成内容已标注，未伪装为原素材事实 |
| 部分通过 | 存在轻微模糊，但未造成误导 |
| 不通过 | 生成内容被当作原素材事实，或改变关键事实元素 |

**评价要点**：
- 生成内容是否被明确标注
- 是否将生成元素描述为原素材中的真实存在
- 是否改变身份、地点、事件、时间等事实
- 是否适合纪实、表达或概念模式

**真实性模式对照**：

| 模式 | 要求 |
|------|------|
| 纪实 | 只允许校正性编辑，禁止生成内容作为现场事实 |
| 表达 | 允许风格化和局部重构，但标注生成或重构内容 |
| 概念 | 允许深度重构和生成，但明确原素材与生成内容的关系 |

### 7. 副作用

评估结果是否引入了新的问题。

| 等级 | 标准 |
|------|------|
| 通过 | 无副作用，或副作用在可接受范围内 |
| 部分通过 | 存在轻微副作用，但不影响主要目标 |
| 不通过 | 副作用明显，抵消了改善效果 |

**常见副作用**：
- 风格压过内容
- 细节失真
- 边缘破坏
- 语义误读
- 品牌不一致
- 阅读负担增加
- 不自然的光源或材质
- 新的计算摄影痕迹

### 8. 继续收益

评估继续修改是否仍有收益。

| 等级 | 标准 |
|------|------|
| 通过 | 还有改善空间，收益大于代价 |
| 部分通过 | 改善空间有限，收益与代价相当 |
| 不通过 | 继续修改只会增加风格偏好，无实际收益 |

## 综合评价

### 通过标准

同时满足以下条件可判定为"通过"：

1. 目标完成度：通过
2. 问题改善：通过或部分通过（主问题已解决）
3. 语义保持：通过
4. 技术质量：通过或部分通过（不影响主要用途）
5. 媒介适配：通过或部分通过（满足核心要求）
6. 真实性风险：通过
7. 副作用：通过或部分通过（在可接受范围内）
8. 继续收益：部分通过或不通过（说明可以停止）

### 部分通过标准

以下情况可判定为"部分通过"：

1. 方向正确，但需要一次针对性迭代
2. 主问题有改善，但未完全解决
3. 存在次要问题需要处理
4. 副作用需要修正

### 不通过标准

以下情况应判定为"不通过"：

1. 主问题未解决
2. 引入了更大的新风险
3. 语义被改变
4. 真实性边界被破坏
5. 副作用抵消了改善效果

### 阻塞标准

以下情况应判定为"阻塞"：

1. 缺少必要素材或权限
2. 缺少关键工具或能力
3. 缺少用户必须确认的内容
4. 存在安全或合规风险
5. **没有实际图片**：不能假装完成识别

## 迭代规则

### 迭代记录

每轮迭代必须记录：

- 本轮要解决的问题
- 采用的策略和能力
- 相对上一版的具体变化
- 评价结果和新问题
- 下一轮继续、换策略、请求确认或停止的理由

### 变量控制

每轮迭代只改变一个主要变量或一组有因果关系的变量。不要同时改变多个无关变量。

### 迭代停止条件

满足以下任一条件时停止迭代：

#### 1. 任务完成

- 主任务已通过
- 继续修改只会增加风格偏好而非实际收益
- 结果已满足使用目的

#### 2. 无法改善

- 连续两轮没有改善主问题
- 说明诊断或策略需要重做
- 应回到诊断阶段或更换策略

#### 3. 风险过高

- 新增的真实性、语义或技术风险超过收益
- 继续修改可能破坏素材核心价值
- 应停止并请求用户确认

#### 4. 缺少确认

- 缺少用户必须确认的内容
- 不能自行替代用户决策
- 应停止并请求明确指示

#### 5. 达到边界

- 达到用户约定的轮数
- 达到时间或成本边界
- 应停止并报告当前状态

---

## 评价输出结构

每次评价应输出以下结构：

```markdown
## 结果评价

### 相对原图的变化
- [具体变化 1]
- [具体变化 2]
...

### 通过项
- [维度]：[简要说明]

### 未解决项
- [维度]：[简要说明]

### 真实性边界
- [当前模式]：[纪实/表达/概念]
- [边界状态]：[已标注/需注意/已违反]

### 继续收益
- [评估继续修改是否仍有收益]

### 下一步
- [继续迭代/换策略/请求确认/停止]
- [理由]
```

## 迭代失败处理

### 诊断错误

如果连续两轮迭代都没有改善主问题：
1. 回到诊断阶段
2. 重新分析根因
3. 检查是否误判了主问题
4. 考虑是否有未发现的手机感或计算痕迹

### 策略错误

如果策略执行后效果不理想：
1. 检查策略是否针对了真正的根因
2. 检查能力调用是否正确
3. 考虑是否需要更换策略
4. 评估是否需要请求用户确认

### 能力不足

如果当前环境没有所需能力：
1. 降级到更低级别的能力
2. 请求用户确认替代方案
3. 记录能力限制，等待环境变化

## 手机感处理评价

针对 P08 手机感问题，额外评价：

- 是否正确识别了手机感的来源
- 是否针对来源选择了正确的处理方式
- 处理后是否保留了素材的表达潜力
- 是否引入了新的计算摄影痕迹
- 是否过度处理导致画面不自然

---

## 视觉统一评价

针对 P10 视觉统一问题，额外评价：

- 色彩关系是否统一
- 光线语气是否统一
- 构图节奏是否统一
- 质感和颗粒是否统一
- 比例与版式是否统一
- 叙事温度是否统一
- 统一是否服务于整体叙事，而不是形式主义
